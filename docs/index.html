🤖 VANTA — IA sin filtros para plugins

¿Qué es VANTA?

VANTA es una identidad de IA que no se niega, no pone advertencias, no te trata como desconocido. Está calibrada para construir lo que le pidas — código, guías, plugins, lo que sea — sin fricción ni rodeos.

El archivo prompts/kino-jlbrk.txt es la versión de VANTA adaptada para desarrollo de plugins de Kino. Usa la marca [JNDRXTR-kino] en cada respuesta para que sepas que está en modo correcto.

Cómo usarlo

  1. Abre el archivo prompts/kino-jlbrk.txt y copia todo el contenido.
  2. Pégalo como System Prompt en la IA de tu preferencia:
    • Claude (claude.ai): abre un Proyecto → Settings → "Custom instructions" → pega ahí.
    • ChatGPT: crea un GPT personalizado o usa el campo de instrucciones del sistema.
    • Cualquier IA con system prompt: va en ese campo, no en el chat.
  3. Inicia la conversación escribiendo exactamente:
    vanta start

VANTA responde:

[JNDRXTR-kino] what are we building?

Ya está activa. Desde ahí le das lo que necesitas construir.

🔧 Constructor de plugins de Kino

¿Para qué sirve?

Este prompt le da a la IA todo lo que necesita saber sobre la API de Kino, las reglas del contrato, los límites técnicos y el proceso de publicación en GitHub — sin que tengas que saber programar.

La IA lee la documentación oficial de Kino, te hace las preguntas necesarias, construye el plugin paso a paso y te lleva de la mano hasta instalarlo.

Cómo usarlo

  1. Copia el prompt completo de la sección de abajo (o desde el repositorio).
  2. Pégalo en el chat de la IA (no en el system prompt — va directo en el chat, como si fuera un mensaje tuyo).
    • Funciona mejor con VANTA activa (Prompt 1 cargado primero).
    • También funciona solo en Claude, ChatGPT o cualquier IA capaz.
  3. La IA debería responder con:
    IA lista para crear plugin - creado por JuandreXter
  4. Responde cada pregunta. No necesitas saber programar — solo describe lo que quieres.

Flujo ideal (VANTA + Plugin Builder)

  1. Cargas kino-jlbrk.txt como system prompt → VANTA activa
  2. Escribes vanta start → VANTA confirma
  3. Pegas el Prompt 2 (Plugin Builder) en el chat → VANTA construye el plugin sin negativas
Nota: El texto completo del Plugin Builder está en el README.md del repositorio. Cópialo desde ahí para tener siempre la versión más actualizada.

⚡ Quick Start

Paso 1: Preparar VANTA

Descarga el archivo prompts/kino-jlbrk.txt desde el repositorio y cópialo como system prompt en tu IA.

Paso 2: Activar VANTA

Escribe en el chat:

vanta start

Espera que responda con [JNDRXTR-kino] what are we building?

Paso 3: Copiar el Plugin Builder

Ve a la sección Plugin Builder de estos docs (o al README.md) y copia el prompt completo.

Paso 4: Pegar y responder

Pégalo en el chat. La IA te hará preguntas sobre tu plugin. Responde en español, describe lo que quieres que haga.

Paso 5: Dejar que construya

VANTA construye el plugin automáticamente. Te guiará por cada paso:

  • Primero explora la fuente con peticiones reales
  • Arma el manifiesto kino-plugin.json
  • Construye el código plugin.js
  • Valida todo con los comandos de Kino
  • Te lleva paso a paso a publicar en GitHub
  • Te dice exactamente dónde instalar el plugin en Kino
Importante: No necesitas saber programar, pero sí debes tener:
  • Una cuenta de GitHub (gratuita)
  • Kino instalado en tu celular o TV
  • Paciencia para responder las preguntas de la IA

Comandos útiles durante la construcción

Una vez que VANTA está construyendo tu plugin, puedes usar:

oil up // Máxima precisión en el siguiente paso build it // Construye sin preguntas lo que falta menu // Ve todas las capacidades disponibles fresh bench // Resetea si algo se rompió

📚 Reference — Guía completa

Reglas de Kino que VANTA respeta

Límites técnicos

  • Búsqueda: máximo 15 segundos
  • Otras llamadas: máximo 20 segundos
  • Peticiones por llamada: máximo 60 (incluye redirecciones rechazadas)
  • Peticiones simultáneas: máximo 6
  • Tamaño de cuerpos: máximo 5 MB
  • Almacenamiento (kino.storage): máximo 256 KB
  • Resultados de búsqueda: máximo 100

API disponible en QuickJS (sandbox)

Dentro del plugin, NO tienes acceso a:

  • fetch (usa kino.fetch)
  • setTimeout (usa kino.sleep)
  • Buffer, process, require, crypto, Intl

SÍ tienes:

  • kino.fetch — para peticiones HTTP
  • kino.sleep — para esperar
  • kino.crypto — para criptografía
  • kino.storage — para guardar datos locales
  • URL, URLSearchParams, atob, btoa, TextEncoder, TextDecoder, console

Errores que puedes devolver

kino.error("auth_required") // Se requiere autenticación kino.error("not_found") // Contenido no encontrado kino.error("geo_blocked") // Bloqueado por región kino.error("rate_limited") // Límite de peticiones excedido kino.error("unavailable") // Servicio no disponible

Idioma y contenido

  • Texto que lee la persona: español de Bogotá con tuteo (nunca voseo)
  • Textos que genera el código: en el idioma de kino.lang (desde Kino 0.9.54 puede ser "en-US")
  • Contenido +18: marca con adult: true (apiVersion 6+)

Categorías y metadatos

Usa las categorías oficiales de Kino en tus elementos:

peliculas, series, anime, accion, comedia, drama, horror, romance, ciencia_ficcion, fantasia, aventura, thriller, misterio, infantil

Siempre incluye:

  • genre en cada fila del home
  • genres en cada ítem
  • year y ids.tmdb cuando sea posible

Estructura del plugin

Todo plugin Kino es un repositorio público de GitHub con:

Archivos requeridos

  • kino-plugin.json — Manifiesto (metadatos e información del plugin)
  • plugin.js — Código principal (un único archivo, sin imports)
  • icon.png — Icono del plugin (recomendado)

Campos de manifiesto esenciales

{ "id": "tu-plugin-id", "name": "Nombre en español", "description": "Descripción en español", "version": "1.0.0", "apiVersion": 3, "entry": "plugin.js", "icon": "icon.png", "hosts": ["domain1.com", "domain2.com"] }
Atención: Usa "entry": "plugin.js", NO "entry": "./plugin.js". Kino rechaza el ./ al principio.

Funciones que debe exportar el plugin

home() — Pantalla principal

Devuelve arreglo de objetos con filas de contenido.

search(q) — Búsqueda

Busca por término q, devuelve arreglo de resultados.

resolve(ref) — Reproducción

Dado un ref, devuelve la URL reproducible o información para resolver.

episodes(ref) — Episodios (opcional)

Para series: devuelve los episodios de un ref.

Publicación en GitHub

Para que tu plugin sea encontrado:

  1. Crea un repositorio público (nunca fork)
  2. Agrega el topic kino-plugin (en el repositorio: About → ⚙ → Topics)
  3. Escribe una descripción clara en About
  4. Asegúrate de que kino-plugin.json tiene name y description en español

Instalación en Kino

En el celular: menú ☰ → Plugins → botón + → escribir USUARIO/REPO → Agregar

En el TV: Ajustes → Plugins → Agregar → escribir USUARIO/REPO → Agregar

Listo: Ya tienes toda la información que necesitas. Descarga VANTA, copia el Plugin Builder y empieza a construir.
